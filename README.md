# Temple Seva Booking System

Temple Seva Booking Application developed using AWS cloud services and Node.js.

## AWS Services Used

- IAM
- EC2
- EBS Volume
- Amazon RDS
- Amazon S3
- Amazon DynamoDB
- CloudWatch

## Features

- Temple Ticket Booking
- User Registration
- Booking Management
- Database Integration
- QR Ticket Download
- Cloud Deployment

## Technologies Used

- HTML
- Node.js
- MySQL
- AWS Cloud

## Project Structure

- index.html
- server.js
- package.json
- package-lock.json
